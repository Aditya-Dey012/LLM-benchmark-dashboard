================================================================================
  LLM BENCHMARK DASHBOARD — COMPLETE SETUP GUIDE (Windows 11 + VSCode Terminal)
================================================================================

HOW TO OPEN THE VSCODE TERMINAL
────────────────────────────────────────────────────────────────────────────────
  • Press  Ctrl + `  (backtick) to open/toggle the integrated terminal
  • Or go to: Terminal → New Terminal from the menu bar
  • The terminal opens at your project root automatically if you opened the
    folder in VSCode (File → Open Folder → select llm-benchmark-dashboard)
  • To open a SECOND terminal tab: click the "+" icon in the terminal panel
    (you will need two terminals: one for backend, one for frontend)

PREREQUISITES TO INSTALL FIRST
────────────────────────────────────────────────────────────────────────────────

STEP 1 — Install Python 3.11+
  • Go to: https://www.python.org/downloads/
  • Download Python 3.11 or later (Windows installer 64-bit)
  • During install: CHECK "Add Python to PATH"
  • Verify in VSCode terminal:
      python --version
    Should print: Python 3.11.x or higher

STEP 2 — Install Node.js (LTS)
  • Go to: https://nodejs.org/
  • Download the LTS version (Windows Installer)
  • Install with default settings
  • Verify in VSCode terminal:
      node --version
      npm --version
    Should print: v20.x.x and 10.x.x (or higher)

STEP 3 — Install Ollama (local LLM server)
  • Go to: https://ollama.com/download
  • Click "Download for Windows"
  • Run the installer (OllamaSetup.exe)
  • Ollama will run as a background service automatically
  • Verify in VSCode terminal:
      ollama --version
    Should print: ollama version 0.x.x

STEP 4 — Pull the LLM Models
  Run these in the VSCode terminal one at a time.
  WARNING: These are large downloads (2-8 GB each). Use Wi-Fi.

      ollama pull gemma:2b
      ollama pull llama3.1:8b
      ollama pull mistral:7b

  Each pull can take 5-30 minutes depending on internet speed.
  To check which models you have:
      ollama list

  To test a model quickly:
      ollama run gemma:2b "Hello, who are you?"
  Press Ctrl+D to exit the chat.

================================================================================
  BACKEND SETUP  (Terminal 1)
================================================================================

  Make sure your VSCode terminal is at the project root:
      c:\#Nexturn\genai\New folder\llm-benchmark-dashboard

  If not, navigate there:
      cd "c:\#Nexturn\genai\New folder\llm-benchmark-dashboard"

STEP 5 — Create a Python virtual environment
      python -m venv .venv

STEP 6 — Activate the virtual environment
      .\.venv\Scripts\Activate.ps1

  If you get a script execution error, run this first:
      Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  Then try activating again.

  When activated, your terminal prompt will show: (.venv)

STEP 7 — Install Python dependencies
      pip install -r requirements.txt

  NOTE: sentence-transformers model (~90 MB) downloads on first benchmark
  run — not during this install step.

STEP 8 — (Optional) Generate the project idea DOCX
      python create_docs.py
  Creates "project_idea.docx" in the current directory.

STEP 9 — Start the backend server
      cd backend
      python run.py

  You should see:
      INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
      INFO:     Application startup complete.

  The SQLite database (benchmark.db) is created automatically.
  API docs available at: http://localhost:8000/docs

  KEEP THIS TERMINAL RUNNING — do not close it.

================================================================================
  FRONTEND SETUP  (Terminal 2 — open a NEW terminal tab with Ctrl+Shift+`)
================================================================================

STEP 10 — Navigate to the frontend folder
      cd "c:\#Nexturn\genai\New folder\llm-benchmark-dashboard\frontend"

STEP 11 — Install frontend dependencies
      npm install

  Installs React, Tailwind, Recharts, and all other packages.
  Takes 1-3 minutes on first run.

STEP 12 — Start the frontend dev server
      npm run dev

  You should see:
      VITE v6.x.x  ready in xxx ms
      ➜  Local:   http://localhost:5173/

  KEEP THIS TERMINAL RUNNING — do not close it.

================================================================================
  USING THE DASHBOARD
================================================================================

STEP 13 — Open your browser
  Go to: http://localhost:5173

  The dashboard will show:
  • Green "Ollama Online" indicator in the header (if Ollama is running)
  • Stats overview with total runs, models, scores
  • Charts (empty until you run benchmarks)

STEP 14 — Run your first benchmark
  1. Click "New Benchmark" in the sidebar
  2. Enter a name (e.g., "Python Explanation Test")
  3. Select task type: "Q&A"
  4. Enter a prompt (or click one of the sample prompt buttons)
  5. Select models (check gemma:2b, llama3.1:8b, mistral:7b)
  6. Click "Run Benchmark"
  7. You'll be redirected to the run detail page
  8. The page auto-refreshes every 3 seconds while running
  9. Results appear as each model completes

  NOTE: First run takes longer because sentence-transformers downloads the
  embedding model (~90 MB, one-time). Subsequent runs are much faster.

STEP 15 — View results
  • See side-by-side responses from all models
  • Compare relevancy scores, latency, and token counts
  • Go back to Dashboard to see updated charts

================================================================================
  OPTIONAL — LangSmith Tracing
================================================================================

If you want to enable LangSmith tracing for observability:
  1. Create a free account at: https://smith.langchain.com/
  2. Go to Settings → API Keys → Create API Key
  3. Open .env (in VSCode explorer) and set:
       LANGSMITH_TRACING=true
       LANGSMITH_API_KEY=ls__your_actual_key_here
  4. Restart the backend (Ctrl+C in Terminal 1, then run python run.py again)
  5. All benchmark runs will appear in smith.langchain.com

================================================================================
  STOPPING THE PROJECT
================================================================================

  • Backend  (Terminal 1): Press Ctrl+C
  • Frontend (Terminal 2): Press Ctrl+C
  • Ollama: Keeps running as a system service (this is normal)
    To stop it: System Tray → right-click Ollama → Quit

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: "Ollama Offline" indicator in dashboard header
  Fix: Make sure Ollama is running. Check system tray or run in terminal:
       ollama serve

Problem: Model not found error when running benchmark
  Fix: Pull the missing model first:
       ollama pull <model-name>
  Then retry the benchmark.

Problem: ".venv\Scripts\Activate.ps1 cannot be loaded"
  Fix: Run this in the VSCode terminal, then activate again:
       Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Problem: VSCode terminal uses cmd.exe instead of PowerShell
  Fix: Click the dropdown arrow (v) next to "+" in the terminal panel
       → select "PowerShell"  (or set it as default in VSCode settings)

Problem: Port 8000 already in use
  Fix: Find and kill the process using the VSCode terminal:
       netstat -ano | findstr :8000
       taskkill /PID <pid_number> /F

Problem: npm install fails
  Fix: Clear cache and retry:
       npm cache clean --force
       npm install

Problem: First benchmark run takes very long
  This is normal — sentence-transformers is downloading the embedding model
  (~90 MB, one-time download). Subsequent runs are fast.
